# Looker Studio · Caso 01

Looker Studio es gratis y se comparte con un link. Se arma con una cuenta de Google **personal** (nunca la de la empresa) sobre dos tablas planas.

| Archivo | Qué es |
|---|---|
| `2026-10-04_Looker_CobranzasDelSur_datos.xlsx` | Datos para subir a Google Sheets: hojas `resultado` (escenario · mes · cartera · cuenta) y `drivers` (escenario · mes · cartera) |
| `build_looker.py` | Regenera el Excel desde `01_datos` |
| `LINKS.md` | Link al informe publicado (cuando esté) |

La guía paso a paso (parámetros de período, campos calculados para copiar y pegar, estilo y páginas) está en `07_docs\2026-10-04_guia-powerbi-looker.html`.
